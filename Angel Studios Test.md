# Cat-alog

Rules

Frontend must be developed in React.

A new blank project is best. Use next.js or the framework of your choice to bootstrap your project.

Ask questions as needed.

Use any libraries you believe will benefit your ability to accomplish the task.

In our projects at Angel Studios we use Tailwind for CSS. If you have experience with Tailwind we’d love to see you use it.

Feel free to Google as needed, please share your screen that you are working on.

We use AI on a daily basis here at Angel, but we ask that you do not use AI to complete this exercise.

We will be using the Cat as a Service API. API docs are here: [https://cataas.com/doc.html](https://cataas.com/doc.html)

User Stories

As a user, I can see all of the cats I have retrieved within this session.

As a user, I can retrieve a random cat and see it’s picture.

As a user, I can retrieve a random cat with a text phrase, using the

:text

parameter.

As a user, I can retrieve a random cat using the tags provided by the API.

As a user, I am delighted by an animation as the new images enter my screen.

As a user, I can navigate to a “detail” page for a single image.

Things of Note

Semantic HTML is important. Be mindful of the document outline you are creating.

Meta data is important. If possible, add appropriate tags that would make this page optimized for search engines.
